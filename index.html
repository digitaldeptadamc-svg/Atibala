Department of Dravyaguna
Atibala
Botanical Name :

  • Abutilon indicum (L.) Sweet

    • Family Name :

  • Malvaceae

    • Local Name :

  • Dodda Tutti

    • Vernacular Name :

  • Hindi – Kanghi

  • English – Indian Mallow

    • Synonyms :

  • Kankatika

  • Vatyalika


    • Habitat :

  • Found throughout India in tropical and subtropical regions, Commonly grows in wastelands, roadsides, cultivated fields, and open grasslands


    • External Morphology :

  • Stem: Erect, much-branched, woody at the base, covered with fine hairs

  • Leaves: Simple, alternate, heart-shaped (cordate), soft, velvety, with serrated margins

  • Flowers: Solitary, yellow to orange-yellow, arising from leaf axils


    • Useful Parts :

  • Root(Mula)


    • Rasadi Panchaka :

  • Rasa - Madhura

  • Guna - Guru, Snigdha

  • Vipaka - Madhura

  • Virya - Sheeta


    • Pharmalogical Action :

  • Anti-inflammatory

  • Analgesic

  • Demulcent


    • Therapeutic Administration:

  • Daurbalya: Root preparations are used as a strengthening tonic

  • Vrana : Fresh leaf paste is applied externally


    • Dose

  • Churna: 3–6 g

  • Kwatha : 50–100 ml

    • Formulation:

  • Atibala Churna

  • Atibala Kwatha
